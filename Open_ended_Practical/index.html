About the Problem

The Dining Philosophers Problem is a classical problem in Operating Systems that demonstrates issues related to process synchronization and resource sharing.

In this problem, five philosophers are seated around a circular table. Each philosopher alternates between two activities: thinking and eating. A single fork is placed between each pair of philosophers, resulting in a total of five forks.

To eat, a philosopher must acquire both the left and right forks. However, since each fork is shared between two adjacent philosophers, this creates a situation where multiple philosophers may compete for limited resources simultaneously.

The Main Challenge

The main challenge is to design a system where:

  • No two neighboring philosophers eat at the same time using the same fork.
  • The system avoids deadlock, where all philosophers hold one fork and wait indefinitely for the other.
  • The system prevents starvation, ensuring every philosopher eventually gets a chance to eat.

This simulation aims to model and analyze these synchronization issues and implement efficient strategies to ensure proper resource allocation without conflicts.
