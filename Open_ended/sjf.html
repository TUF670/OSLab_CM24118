What is Shortest Job First?

Shortest Job First (SJF) is a scheduling algorithm that selects the process with the smallest execution time (burst time) to execute next. It is highly efficient because it significantly reduces the average waiting time for a given set of processes.

Non-Preemptive SJF

Once the CPU is assigned to a process, it cannot be interrupted until it completes its entire burst cycle.

Preemptive SJF (SRTF)

Also known as Shortest Remaining Time First. If a new process arrives with a burst time shorter than the remaining time of the current process, the CPU is switched.

Algorithm Execution Steps

  1. Step 1: Sort all processes according to their Arrival Time.
  2. Step 2: Identify the process with the minimum Burst Time among those already arrived in the Ready Queue.
  3. Step 3: Allocate the CPU to that process.
  4. Step 4: Calculate Turnaround Time (Completion Time - Arrival Time).
  5. Step 5: Calculate Waiting Time (Turnaround Time - Burst Time).

Advantages

  • Provides the minimum average waiting time.
  • Highly effective for long-term scheduling.
  • Better performance for short-duration processes.

Disadvantages

  • Causes Starvation: Long processes may never execute if short jobs keep arriving.
  • Difficult to implement because the exact burst time of an upcoming process cannot be known.
